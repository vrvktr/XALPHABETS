# Alphabet Buttons

A responsive React + Vite application styled with Bootstrap 5.

## Features

- A–Z alphabet buttons
- Appends letters when buttons or physical keys are pressed
- Backspace button and physical Backspace support
- Responsive layout
- Required `.output` and `.key` class names
- Keyboard listener is cleaned up when the component unmounts

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```
